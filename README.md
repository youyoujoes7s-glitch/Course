## 🧩 MCP — Model Context Protocol

1. **[Anthropic Academy — Introduction to Model Context Protocol](https://anthropic.skilljar.com/introduction-to-model-context-protocol)** 🆓 🏅 🧪
   الكورس الرسمي من Anthropic نفسها. بتبني MCP server و client من الصفر بالـ Python، وتتعلم التلات primitives (tools / resources / prompts) عمليًا.

2. **[Anthropic Academy — MCP: Advanced Topics](https://anthropic.skilljar.com/model-context-protocol-advanced-topics)** 🆓 🏅 🧪
   الجزء المتقدم من نفس السلسلة الرسمية: sampling، notifications، transports (stdio / StreamableHTTP)، وأنماط الإنتاج (production patterns).

3. **[DeepLearning.AI — MCP: Build Rich-Context AI Apps with Anthropic](https://learn.deeplearning.ai/courses/mcp-build-rich-context-ai-apps-with-anthropic)** 🆓 🏅 🧪
   بالتعاون المباشر مع Anthropic، وبيقدّمه Elie Schoppik (Head of Technical Education في Anthropic). فيه notebooks تطبيقية.

4. **[Udemy — MCP Crash Course: Complete Model Context Protocol in a Day (Eden Marco)](https://www.udemy.com/course/model-context-protocol/)** 💰 🧪
   Bestseller على يوديمي، 8.5 ساعة و90 محاضرة. تطبيق عملي كامل: بناء servers وclients وتغطية الـ MCP Security.

5. **[KodeKloud — Model Context Protocol Explained + Hands-on Lab](https://www.classcentral.com/classroom/youtube-what-is-mcp-model-context-protocol-explained-free-lab-495407)** 🆓 🧪
   شرح + معمل تفاعلي شغال من المتصفح مباشرة من غير أي إعداد محلي.

6. **[freeCodeCamp — Intro to MCP Servers with Python (FastMCP)](https://www.youtube.com/watch?v=DosHnyq78xY)** 🆓 🧪
   3 مشاريع عملية: calculator بـ STDIO وHTTP Stream، تكامل مع API، واختبار الـ MCP مع GitHub Copilot.

7. **[Hugging Face — MCP Course](https://huggingface.co/learn/mcp-course/unit0/introduction)** 🆓 🏅
   كورس رسمي مجاني ومعتمد، نظري وعملي مع تمارين.

8. **[MCP — Model Context Protocol End-To-End Course 2026 (Playlist)](https://www.youtube.com/playlist?list=PL6tW9BrhiPTCDteflzehKS6Cn3a79-iCs)** 🆓
   بلاي ليست شاملة من الأساسيات لحد النشر.

## 🤖 Agentic AI

1. **[Udemy — The Complete Agentic AI Engineering Course (Ed Donner)](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/)** 💰 🧪
   الأقوى والأشمل في السوق حاليًا. برنامج 6 أسابيع بـ 8 مشاريع حقيقية (Career Digital Twin، Deep Research App، Engineering Team، Trading Platform...) بتغطي OpenAI Agents SDK وCrewAI وLangGraph وAutoGen، وبينتهي بأسبوع كامل عن MCP.

2. **[Krish Naik — Complete Agentic AI Course In 10 Hours](https://www.youtube.com/watch?v=rV3HJ4LEZ7k)** 🆓 🧪
   Langchain، Langgraph، RAG، Vectorless RAG، Deep Agents، Guardrails، Evals، LLM Gateways — ومعاه GitHub repos لكل جزء تطبّق عليه بنفسك.

3. **[freeCodeCamp — LangGraph Complete Course for Beginners](https://youtu.be/jGg_1h0qzaM)** 🆓 🧪
   3 ساعات، بتبني 5 agents مختلفة من الصفر بالكود بالإضافة لتكامل RAG.

4. **[Hugging Face — AI Agents Course](https://huggingface.co/learn/agents-course/unit0/introduction)** 🆓 🏅 🧪
   كورس رسمي بشهادتين (Fundamentals و Full Completion)، فيه assignments عملية لازم تعملها عشان تكمل.

5. **[Intellipaat — Complete Agentic AI Course Free 2026](https://www.youtube.com/watch?v=3UKvRgfy2qY)** 🆓

6. **[Intellipaat — Agentic AI Full Course for Free 2026](https://www.youtube.com/watch?v=wDs2egmmjFU)** 🆓

7. **[AI Agents Full Course 2026: Master Agentic AI (2 Hours)](https://www.youtube.com/watch?v=EsTrWCV0Ph4)** 🆓
